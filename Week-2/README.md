# Week 1 – Think Like an Engineer

## Overview

Week 1 introduces the students to the world of web development and software engineering. The goal is to build confidence, spark curiosity, and help every student create and publish their first personal portfolio website.

The emphasis is not on memorizing HTML tags but on understanding how websites work, learning by building, and developing the confidence to continue learning.

---

# Weekly Theme

**Think Like an Engineer**

Students will:

- Learn how websites are built.
- Understand the relationship between HTML, CSS, and JavaScript.
- Explore software engineering through real-world examples.
- Build and publish a personal portfolio website.
- Begin using AI responsibly as a learning assistant.

---

# Learning Outcomes

By the end of Week 1, every student should be able to:

- Explain what a website is.
- Describe the purpose of HTML and CSS.
- Create a simple multi-section webpage.
- Add images, links, headings, and lists.
- Style a webpage using CSS.
- Publish a website using GitHub Pages.
- Share a live website URL.
- Explain every line of code they wrote.

---

# Weekly Deliverable

✅ A live personal portfolio website published with GitHub Pages.

The portfolio should include:

- Home section
- About Me
- Interests or Hobbies
- Favourite Technology
- Contact section
- Basic styling
- Images
- Working links

# Session Overview

## Session 1 – Orientation & Think Like an Engineer

Objectives

- Welcome students.
- Introduce the programme.
- Meet the engineering team.
- Demonstrate robotics.
- Explore how websites work.
- Allow students to choose a personal project idea.

Deliverable

- Students understand the programme.
- Students have selected a project idea.

---

## Session 2 – Building Your First Website

Objectives

- Learn HTML basics.
- Understand webpage structure.
- Create the first version of a personal portfolio.
- Learn basic CSS.

Deliverable

- Portfolio website created locally.

---

## Session 3 – Publishing Your Website

Objectives

- Learn GitHub basics.
- Publish using GitHub Pages.
- Improve website appearance.
- Present work during Demo Time.

Deliverable

- Live portfolio website.

---

# AI Learning Focus

Week 1 Rule:

**AI Explains**

Students may ask AI:

- What does this tag mean?
- Why am I getting this error?
- Explain this code.

Students may NOT ask AI to generate complete solutions.
