# Demo Portfolio Website

This project is the reference website used throughout the Kokoodi AI Makers Camp.

## Purpose

The project demonstrates how a simple HTML page can gradually evolve into a complete personal portfolio.

Students will customise the project by replacing the content with their own information and adding new features as they learn.

## Learning Progression

### Week 1
- HTML structure
- Images
- Headings
- Paragraphs
- Lists
- Links

### Week 2
- CSS styling
- Colours
- Fonts
- Layout
- Responsive design

### Week 3
- JavaScript
- Buttons
- Events
- DOM manipulation

### Week 4
- Portfolio improvements
- Project gallery
- Contact section
- Final showcase

## Goal

By the end of the programme, each student will have a professional portfolio website published on GitHub Pages.
