# Session Overview

Today the Builders will begin turning their ideas into real websites.

Instead of following the same project, each Builder will continue developing their own idea while learning the same HTML concepts.

This session introduces HTML through building rather than memorising.

Students should leave today's session with the first version of their homepage committed to GitHub.

---

# Learning Objectives

By the end of this session, each Builder should be able to:

- Explain what HTML is.
- Understand how websites are structured.
- Create a homepage using HTML.
- Add headings and paragraphs.
- Create ordered and unordered lists.
- Insert images.
- Create hyperlinks.
- Save and commit their work to GitHub.
- Explain every line they wrote.

# Session Schedule

## Part 1 – Welcome Back (10 Minutes)

### Discussion

Ask each Builder:

- What did you enjoy from Session 1?
- What is your project about?
- What feature are you most excited to build?

Explain that today they are building the first version of their product.

---

## Part 2 – Applying Design Thinking (10 Minutes)

Briefly connect today's lesson to the earlier UI/UX session.

Ask questions such as:

- What makes a website easy to use?
- Why is the homepage important?
- What should visitors see first?

Explain that professional developers plan before writing code.

---

## Part 3 – What is HTML? (15 Minutes)

Explain HTML in simple language.

HTML is the structure of every website.

Use the house analogy.

- HTML builds the structure.
- CSS adds the decoration.
- JavaScript adds behaviour.

Show a simple webpage and explain that browsers read HTML files to display websites.

---

# HTML Tags Covered

Introduce only the tags students need today.

```html
<h1>
<h2>
<p>
<ul>
<ol>
<li>
<img>
<a>
```

Explain each one with a simple example.

---

# Live Coding (30 Minutes)

Create a homepage together.

Suggested structure:

```html
<!DOCTYPE html>
<html>

<head>
    <title>My Project</title>
</head>

<body>

<h1>Project Title</h1>

<p>Welcome to my website.</p>

</body>

</html>
```

Build slowly.

Allow everyone to type every line.

Pause regularly.

Ask students what each tag does.

# AI Exercise

Students may use AI only for explanations.

Example prompts:

"What does the  tag do?"

"Explain the difference between h1 and h2."

"Why do we use paragraphs?"

Students are **not allowed** to ask AI to generate their homepage.

# Instructor Notes

Keep the session practical.

Avoid long lectures.

Demonstrate every concept before asking students to build.

Encourage experimentation.

Celebrate progress rather than perfection.

Keep relating HTML back to each Builder's project idea.

The objective is not to finish the website.

The objective is to build a strong HTML foundation that will be styled with CSS during Week 2.
